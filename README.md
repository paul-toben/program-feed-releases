# Program Feed releases

Downloads of **Program Feed** for macOS. Each release is signed with Developer ID and
notarized by Apple.

**[Download the latest version](https://github.com/paul-toben/program-feed-releases/releases/latest)**:
unzip it and move Program Feed to Applications. It needs macOS 26 or later.

Once installed, Program Feed checks for new versions itself (Program Feed ▸ Check for
Updates…).

This repository holds only the built app and `appcast.xml`, the update feed the app reads
through GitHub Pages at <https://paul-toben.github.io/program-feed-releases/appcast.xml>.
The source code is not here.
